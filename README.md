# 🎮 Tic-Tac-Toe Game

A modern, fully-featured Tic-Tac-Toe game with AI opponent, score tracking, and beautiful animations.

## ✨ Features

- **Two Game Modes**: 
  - 👥 Player vs Player
  - 🤖 Player vs AI (Smart AI)
- **Score Tracking**: Keeps track of wins for X, O, and ties
- **Beautiful Animations**: Smooth pop-in effects and win highlights
- **Sound Effects**: Audio feedback on moves
- **Responsive Design**: Works on desktop and mobile
- **Win Detection**: Automatic win/tie detection with highlighting
- **Game Overlay**: Victory modal with play again option

## 🚀 How to Play

1. Open `index.html` in your browser
2. Choose game mode: Player vs Player or Player vs AI
3. Click on any cell to make your move
4. First to get 3 in a row wins!
5. Track your scores at the top

## 🎯 Game Controls

- **New Game**: Reset the current game
- **Reset Score**: Clear all scores
- **Mode Toggle**: Switch between Player and AI mode

## 🤖 AI Logic

The AI uses a strategic approach:
1. Tries to win immediately
2. Blocks player from winning
3. Takes center if available
4. Takes corners
5. Takes edges
